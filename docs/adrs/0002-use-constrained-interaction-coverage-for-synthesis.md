# Use constrained interaction coverage for scenario synthesis

Phase 4.5 defines synthesis coverage over Coverage cells rather than generated-file counts or surface-text diversity. The gate requires every eligible axis value and eligible pairwise interaction across journey path, Persona archetype, Knowledge level, Complication, fixture-state equivalence class, and Fitness target, plus independent coverage of every approved journey edge and known planted-defect class; complete valid-cell coverage is reported when tractable but is not universally required. Pair eligibility is a reviewed artifact, and every excluded pair requires an explicit justification so constraints cannot silently hide gaps.

This chooses interaction coverage over both marginal-only coverage, which misses cross-axis failures, and mandatory Cartesian coverage, which makes library size grow combinatorially. Fitness-target coverage is deliberately limited to known defect classes; coverage-guided generation is the future mechanism for finding behavior outside that closed set. Two scenarios are same-cell equivalent exactly when all Coverage cell axes match, regardless of surface realization, and that definition is shared with near-duplicate control.
