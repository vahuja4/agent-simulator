# Overview-level fluency established before the course began

Before the first lesson, Vishal built and iterated five visual explainers of
this system (SAGE personas, the scenario factory, the ALMITA paper, its use in
the repo, and a unified story). Evidence of understanding: caught a display
bug that hid two curveballs, challenged the claim that generation depends on
existing scenarios (it doesn't, at runtime), and asked for the provenance of
the six curveballs and an example of a journey-borne rule.

Implication: skip big-picture teaching entirely. Start at code level — the
message/adapter seam, then component internals (simulator, judge, assertions,
orchestrator, synthesis modules). The overviews in
`agent-simulator-story.html` serve as recap material, not lesson content.
